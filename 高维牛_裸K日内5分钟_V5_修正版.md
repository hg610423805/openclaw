# 一、完整交易步骤

## 步骤1：日线趋势判断（定方向）

```
判断方法：
□ 日线 MA20 方向向上 → 只做多
□ 日线 MA20 方向向下 → 只做空
□ 日线 MA20 走平 → 不交易

结论：
- 日线上涨趋势 → 5分钟只做多
- 日线下跌趋势 → 5分钟只做空
- 日线震荡 → 休息
```

## 步骤2：5分钟顶底分型判断

```
5分钟K线找顶底分型：
底分型（做多信号）：
- 中间K线最低点 = 3根K线最低
- 中间K线收盘价 > 前后K线收盘价

顶分型（做空信号）：
- 中间K线最高点 = 3根K线最高  
- 中间K线收盘价 < 前后K线收盘价
```

## 步骤3：开仓（方向一致 + 分型信号）

```
【做多条件】
1. 日线趋势向上（MA20向上）
2. 5分钟出现底分型
3. 底分型后价格突破最高点（收盘价突破）
4. 放量确认

【做空条件】
1. 日线趋势向下（MA20向下）
2. 5分钟出现顶分型
3. 顶分型后价格跌破最低点（收盘价跌破）
4. 放量确认

【禁止】
- 日线向上，5分钟出现顶分型做空 → 不开仓
- 日线向下，5分钟出现底分型做多 → 不开仓
```

## 步骤4：止损设置（顶底分型）

```
【做多止损】
止损位：底分型最低点下方1跳（或根据分型最低点）

入场点：底分型突破点
止损点：底分型最低点

举例：
底分型最低点 = 4200
止损点 = 4199（下方1跳）

【做空止损】
止损位：顶分型最高点上方1跳（或根据分型最高点）

入场点：顶分型跌破点  
止损点：顶分型最高点

举例：
顶分型最高点 = 4200
止损点 = 4201（上方1跳）
```

## 步骤5：止盈（顶底分型移动跟踪）

```
【做多止盈移动】
条件：出现新的顶分型（或价格跌破重要支撑）

第1目标：+2% 止盈1/3
第2目标：出现顶分型 止盈1/3
第3目标：趋势破坏（高点被跌破） 全部平仓

移动跟踪：
- 持仓期间，持续跟踪新的顶分型
- 出现第一个顶分型 → 止盈1/3
- 出现第二个顶分型 → 再止盈1/3
- 趋势破坏（最近低点被跌破）→ 全部平仓

【做空止盈移动】
条件：出现新的底分型（或价格突破重要压力）

第1目标：+2% 止盈1/3
第2目标：出现底分型 止盈1/3  
第3目标：趋势破坏（低点被涨破） 全部平仓

移动跟踪：
- 持仓期间，持续跟踪新的底分型
- 出现第一个底分型 → 止盈1/3
- 出现第二个底分型 → 再止盈1/3
- 趋势破坏（最近高点被涨破）→ 全部平仓
```

```python
# -*- coding: utf-8 -*-
"""
高维牛裸K日内5分钟策略 V5 - 顶底分型止损止盈
"""

from tqsdk import TqApi, TqAuth
from tqsdk.ta import MA
import numpy as np
from datetime import datetime, time

class GaoWeiNiuV5Strategy:
    
    def __init__(self, config):
        self.api = TqApi(auth=TqAuth(config['account'], config['password']))
        self.symbols = config.get('symbols', ['SHFE.rb2505'])
        self.account_equity = config['account_equity']
        
        # 参数
        self.risk_ratio = config.get('risk_ratio', 0.01)    # 1%
        self.max_position = config.get('max_position', 30)   # 30%
        self.target_pct = config.get('target_pct', 0.02)     # 2%首目标
        
        # 持仓状态
        self.positions = {}
        self.daily_pnl = 0
        self.daily_trades = 0
        
    # ==================== 步骤1: 日线趋势 ====================
    
    def get_daily_trend(self, symbol):
        """日线趋势判断"""
        # 获取日K线
        daily_k = self.api.get_kline_serial(symbol, 24*60*60*1000, 60)  # 60天日K
        ma20 = MA(daily_k, 20)
        ma20_val = ma20.iloc[-1]['MA']
        ma20_prev = ma20.iloc[-5]['MA']  # 5天前
        
        current = daily_k.iloc[-1]['close']
        
        if current > ma20_val and ma20_val > ma20_prev:
            return 'uptrend'
        elif current < ma20_val and ma20_val < ma20_prev:
            return 'downtrend'
        return 'sideway'
    
    # ==================== 步骤2: 5分钟顶底分型 ====================
    
    def get_5min_klines(self, symbol):
        return self.api.get_kline_serial(symbol, 5*60*1000, 100)
    
    def find_fractal(self, klines):
        """识别顶底分型"""
        if len(klines) < 5:
            return None, None, None
        
        recent = klines.tail(5).reset_index(drop=True)
        
        # 底分型
        mid = recent.iloc[2]
        if (mid['low'] < recent.iloc[1]['low'] and 
            mid['low'] < recent.iloc[3]['low'] and
            mid['close'] > recent.iloc[1]['close'] and 
            mid['close'] > recent.iloc[3]['close']):
            
            # 返回分型类型、最低点点、索引
            return 'bottom', mid['low'], recent.index[2]
        
        # 顶分型
        if (mid['high'] > recent.iloc[1]['high'] and 
            mid['high'] > recent.iloc[3]['high'] and
            mid['close'] < recent.iloc[1]['close'] and 
            mid['close'] < recent.iloc[3]['close']):
            
            return 'top', mid['high'], recent.index[2]
        
        return None, None, None
    
    def check_breakout(self, klines, fractal_idx, direction):
        """检查是否突破分型"""
        if fractal_idx is None or fractal_idx < 0:
            return False, 0
        
        # 突破分型后的K线
        if len(klines) <= fractal_idx + 1:
            return False, 0
        
        after_fractal = klines.iloc[fractal_idx+1:]
        current = klines.iloc[-1]
        
        if direction == 'long':
            # 突破底分型高点
            fractal_high = klines.iloc[fractal_idx]['high']
            return current['close'] > fractal_high, fractal_high
        else:
            # 跌破顶分型低点
            fractal_low = klines.iloc[fractal_idx]['low']
            return current['close'] < fractal_low, fractal_low
    
    def check_volume(self, klines):
        """量能确认"""
        if len(klines) < 20:
            return False
        avg = klines['volume'].iloc[-20:].mean()
        return klines.iloc[-1]['volume'] > avg * 1.5
    
    # ==================== 步骤3: 入场 ====================
    
    def get_entry_signal(self, symbol):
        """获取入场信号"""
        # 步骤1: 日线趋势
        daily_trend = self.get_daily_trend(symbol)
        
        # 步骤2: 5分钟顶底分型
        klines = self.get_5min_klines(symbol)
        fractal_type, fractal_price, fractal_idx = self.find_fractal(klines)
        
        # 步骤3: 突破确认 + 量能
        current = klines.iloc[-1]['close']
        
        # 做多：日线向上 + 底分型突破
        if daily_trend == 'uptrend' and fractal_type == 'bottom':
            broken, level = self.check_breakout(klines, fractal_idx, 'long')
            vol_ok = self.check_volume(klines)
            
            if broken and vol_ok:
                # 止损：底分型最低点下方
                stop = fractal_price * 0.999  # 下方0.1%
                
                return {
                    'direction': 'long',
                    'entry': current,
                    'stop_loss': stop,
                    'fractal_low': fractal_price,  # 记录分型低点用于跟踪
                    'signal': f'日线向上+5分钟底分型突破'
                }
        
        # 做空：日线向下 + 顶分型跌破
        if daily_trend == 'downtrend' and fractal_type == 'top':
            broken, level = self.check_breakout(klines, fractal_idx, 'short')
            vol_ok = self.check_volume(klines)
            
            if broken and vol_ok:
                # 止损：顶分型最高点上方
                stop = fractal_price * 1.001  # 上方0.1%
                
                return {
                    'direction': 'short',
                    'entry': current,
                    'stop_loss': stop,
                    'fractal_high': fractal_price,  # 记录分型高点用于跟踪
                    'signal': f'日线向下+5分钟顶分型跌破'
                }
        
        return None
    
    # ==================== 步骤4: 止损（顶底分型） ====================
    
    def check_stop_loss(self, symbol, pos):
        """根据顶底分型检查止损"""
        klines = self.get_5min_klines(symbol)
        current = klines.iloc[-1]['close']
        
        if pos['direction'] == 'long':
            # 做多：跌破分型低点止损
            if current < pos['stop_loss']:
                return True, '跌破分型低点'
        else:
            # 做空：涨破分型高点止损
            if current > pos['stop_loss']:
                return True, '涨破分型高点'
        
        return False, ''
    
    # ==================== 步骤5: 止盈（顶底分型移动） ====================
    
    def check_take_profit(self, symbol, pos):
        """根据顶底分型移动止盈"""
        klines = self.get_5min_klines(symbol)
        current = klines.iloc[-1]['close']
        entry = pos['entry']
        
        if pos['direction'] == 'long':
            pnl_pct = (current - entry) / entry
            
            # 检查是否出现新的顶分型（止盈信号）
            fractal_type, fractal_price, _ = self.find_fractal(klines)
            
            # 第1目标：+2%
            if pnl_pct >= 0.02 and not pos.get('tp1_done', False):
                return {'action': 'tp1', 'reason': '达到2%目标'}
            
            # 出现顶分型
            if fractal_type == 'top' and not pos.get('tp2_done', False):
                return {'action': 'tp2', 'reason': '出现顶分型'}
            
            # 趋势破坏（低点被跌破）
            recent_low = klines['low'].tail(5).min()
            if current < recent_low and not pos.get('tp3_done', False):
                return {'action': 'tp3', 'reason': '趋势破坏'}
        
        else:  # 做空
            pnl_pct = (entry - current) / entry
            
            # 检查是否出现新的底分型
            fractal_type, fractal_price, _ = self.find_fractal(klines)
            
            if pnl_pct >= 0.02 and not pos.get('tp1_done', False):
                return {'action': 'tp1', 'reason': '达到2%目标'}
            
            if fractal_type == 'bottom' and not pos.get('tp2_done', False):
                return {'action': 'tp2', 'reason': '出现底分型'}
            
            recent_high = klines['high'].tail(5).max()
            if current > recent_high and not pos.get('tp3_done', False):
                return {'action': 'tp3', 'reason': '趋势破坏'}
        
        return None
    
    # ==================== 执行 ====================
    
    def open_position(self, symbol, signal):
        if not self.can_trade():
            return
        
        entry = signal['entry']
        stop = signal['stop_loss']
        
        # 计算手数
        risk = self.account_equity * self.risk_ratio
        quote = self.api.get_quote(symbol)
        diff = abs(entry - stop)
        
        if diff == 0:
            diff = entry * 0.001
        
        contract = self.api.get_contract(symbol)
        size = risk / (diff * contract.volume_tick * contract.margin)
        size = min(int(size), 10)  # 限制最大手数
        
        if signal['direction'] == 'long':
            self.api.insert_order(symbol, 'BUY', 'OPEN', size, entry)
        else:
            self.api.insert_order(symbol, 'SELL', 'OPEN', size, entry)
        
        self.positions[symbol] = {
            'direction': signal['direction'],
            'entry': entry,
            'stop_loss': stop,
            'size': size,
            'entry_time': datetime.now()
        }
        
        print(f"开仓: {symbol} {signal['direction']} {size}手 @ {entry}")
        self.daily_trades += 1
    
    def close_position(self, symbol, action_info):
        if symbol not in self.positions:
            return
        
        pos = self.positions[symbol]
        quote = self.api.get_quote(symbol)
        current = quote.last_price
        
        if pos['direction'] == 'long':
            self.api.insert_order(symbol, 'SELL', 'CLOSE', pos['size'], current)
            pnl = (current - pos['entry']) * pos['size']
        else:
            self.api.insert_order(symbol, 'BUY', 'CLOSE', pos['size'], current)
            pnl = (pos['entry'] - current) * pos['size']
        
        print(f"平仓: {symbol} {action_info['reason']} 盈亏: {pnl:.2f}")
        self.daily_pnl += pnl
        del self.positions[symbol]
    
    def can_trade(self):
        if self.daily_pnl < -self.account_equity * 0.02:
            return False
        if self.daily_trades >= 5:
            return False
        return True
    
    def run(self):
        print("="*50)
        print("高维牛V5策略启动 - 顶底分型止损止盈")
        print("="*50)
        
        while True:
            try:
                for symbol in self.symbols:
                    pos = self.api.get_position(symbol)
                    net = pos.pos_long - pos.pos_short
                    
                    if net == 0:  # 无持仓
                        if self.can_trade():
                            signal = self.get_entry_signal(symbol)
                            if signal:
                                self.open_position(symbol, signal)
                    else:  # 有持仓
                        if symbol in self.positions:
                            # 检查止损
                            need_stop, reason = self.check_stop_loss(symbol, self.positions[symbol])
                            if need_stop:
                                self.close_position(symbol, {'reason': reason})
                                continue
                            
                            # 检查止盈
                            tp_info = self.check_take_profit(symbol, self.positions[symbol])
                            if tp_info:
                                self.close_position(symbol, tp_info)
                
                import time
                time.sleep(10)
                
            except Exception as e:
                print(f"错误: {e}")
                time.sleep(30)


if __name__ == "__main__":
    config = {
        'account': '你的天勤账号',

        'account_equity': 100000,
        'risk_ratio': 0.01,
        'symbols': ['SHFE.rb2505'],
    }
    
    strategy = GaoWeiNiuV5Strategy(config)
    strategy.run()
```
