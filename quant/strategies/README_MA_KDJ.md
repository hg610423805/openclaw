# 均线+KDJ 趋势跟踪策略配置

## 📋 策略参数

```python
# 基础配置
SYMBOL = "SHFE.rb2505"      # 交易合约
INITIAL_CAPITAL = 100000    # 初始资金 10 万
MAX_POSITION_RATIO = 0.5    # 最大仓位 50%
MAX_DAILY_TRADES = 3        # 每日最多 3 次交易
CONTRACT_ROLL_DAYS = 10     # 到期前 10 天移仓

# 指标参数
EXPMA_FAST = 13             # 快线周期
EXPMA_SLOW = 26             # 慢线周期
KDJ_PERIOD = 9              # KDJ 周期

# K 线周期
MONITOR_INTERVAL = "30"     # 30 分钟定方向
TRADE_INTERVAL = "5"        # 5 分钟交易

# Tick 值（按品种修改）
TICK_SIZE = {
    "rb": 1,      # 螺纹钢 1 元/吨
    "hc": 1,      # 热卷 1 元/吨
    "m": 1,       # 豆粕 1 元/吨
    "TA": 2,      # PTA 2 元/吨
    "FG": 1,      # 玻璃 1 元/吨
    "SM": 2,      # 硅锰 2 元/吨
    "SF": 2,      # 硅铁 2 元/吨
    "UR": 1,      # 尿素 1 元/吨
    "JD": 1,      # 鸡蛋 1 元/500kg
}
```

## 🚀 使用方法

### 1. 回测模式
```bash
cd quant/strategies
python ma_kdj_trend_backtest.py --symbol rb2505 --start 2025-01-01 --end 2025-03-22
```

### 2. 实盘模式
```bash
# 先修改 ma_kdj_trend.py 中的天勤账号密码
python ma_kdj_trend.py
```

### 3. 批量回测多个品种
```bash
python batch_backtest.py --symbols rb,hc,m,SM,SF --years 2024,2025
```

## 📊 策略逻辑

```
┌─────────────────────────────────────────────────────────┐
│                    30 分钟定方向                          │
├─────────────────────────────────────────────────────────┤
│  EXPMA13 > EXPMA26  →  只做多不做空                      │
│  EXPMA13 < EXPMA26  →  只做空不做多                      │
└─────────────────────────────────────────────────────────┘
                          ↓
┌─────────────────────────────────────────────────────────┐
│                    5 分钟入场信号                         │
├─────────────────────────────────────────────────────────┤
│  做多方式 1: 30 分 J<20 + 5 分 J<20 + 双均线多 + K 线强势    │
│  做多方式 2: 30 分 J<20 + 5 分金叉                         │
│  做空方式 1: 30 分 J>80 + 5 分 J>80 + 双均线空 + K 线弱势    │
│  做空方式 2: 30 分 J>80 + 5 分死叉                         │
└─────────────────────────────────────────────────────────┘
                          ↓
┌─────────────────────────────────────────────────────────┐
│                    止损止盈管理                          │
├─────────────────────────────────────────────────────────┤
│  初始止损：前 K 线极值 ±1tick 或分型极值                   │
│  移动止损：新分型极点优于前分型时更新                     │
│  止盈出场：5 分钟均线反向交叉                              │
└─────────────────────────────────────────────────────────┘
```

## ⚠️ 注意事项

1. **移仓换月**: 旧合约到期前 10 天强制平仓，切换到新主力合约
2. **每日限次**: 每天最多交易 3 次，避免过度交易
3. **仓位控制**: 单笔开仓不超过总资金 50%
4. **Tick 值**: 不同品种 Tick 值不同，需在配置中修改
5. **合约乘数**: 默认 10 吨/手，不同品种需调整
6. **账号配置**: 天勤账号已配置（`quant/config.py`），无需重复填写
