## 📊 分型+移动止损策略回测

### 策略核心逻辑

**开仓条件**：
- 底分型确认（3 根 K 线，中间最低）+ 底分型抬高 → 开多
- 顶分型确认（3 根 K 线，中间最高）+ 顶分型降低 → 开空
- 分型力度过滤：中间 K 线比左右至少低/高 N 个 tick

**止损逻辑**（关键修正）：
- ❌ 修正前：止损 = 上一个分型极值（距离远，亏损大）
- ✅ 修正后：止损 = 开仓分型极值（距离近，亏损小）

**移动止损**：
- 多单：出现新底分型 → 止损上移到新底分型低点
- 空单：出现新顶分型 → 止损下移到新顶分型高点

### 回测参数

| 参数 | 值 |
|------|-----|
| 交易周期 | 60 分钟 K 线 |
| K 线数量 | 3000 根（约 1-2 年） |
| 品种 | 锰硅 (KQ.m@CZCE.SM) |
| 仓位 | 50%（按保证金 10% 计算） |
| 分型间隔 | 1 根 K 线 |
| 分型力度 | >=0 tick（不过滤） |

## 📝 开发过程记录

### 问题排查

1. **K 线数据时间错误**：TQSDK backtest 模式返回 2016 年数据，改用实时 API 获取最近 3000 根
2. **止损逻辑错误**：原逻辑止损=上一个分型极值，导致亏损过大，修正为开仓分型极值
3. **变量作用域问题**：period_str 在 if 块外使用导致 UnboundLocalError

### 教训

- 回测前务必验证 K 线数据的时间和有效性
- 止损逻辑是策略核心，需仔细验证
- 变量作用域要注意，尤其是条件块内定义的变量
