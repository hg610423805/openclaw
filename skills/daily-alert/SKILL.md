# 每日新闻自动提醒技能

## 功能

每天早上 8 点自动推送：
1. **期货锰硅** 过去 24 小时重大消息及操作建议
2. **A 股板块**（算力/电力/储能/机器人/商业航天）过去 24 小时重大消息

## 安装

### 方法 1：Windows 任务计划（推荐）

```powershell
# 以管理员身份运行
cd C:\Users\17699\.openclaw\workspace\skills\daily-alert
powershell -ExecutionPolicy Bypass -File setup_task.ps1
```

### 方法 2：OpenClaw Heartbeat

HEARTBEAT.md 已配置，每天早上 8 点自动检查

### 方法 3：手动执行

```bash
cd skills/daily-alert
python fetch_news.py
```

## 配置

### 新闻源配置
编辑 `config.json` 自定义新闻源 URL

### 推送配置
- 本地文件：`daily_report.txt`
- 飞书：配置 Webhook（可选）
- 微信/邮件：后续扩展

## 使用

### 自动执行
每天早上 8:00 自动推送到飞书

### 手动触发
- `/daily-alert`
- `今日新闻`
- `期货消息`
- `A 股消息`

## 注意事项

1. 需要配置 web_search API key 才能获取实时新闻
2. 部分网站有反爬，建议降低抓取频率
3. 自动分析仅供参考，需人工判断
