1死鱼口诀——最简单的方向判定

这是整个知识库里最适合新手的公式，来自Q020和Q031。做日内5分钟交易时，方向判断只需要看一样东西：

日线最近出现的是底分型 → 只做多
日线最近出现的是顶分型 → 只做空

为什么叫"死鱼"？因为这个方法简单到像死鱼一样——不需要动脑子，看一眼日线就知道今天只做什么方向。

图1：死鱼口诀示意 · 日线走势决定5分钟交易方向
"5分钟的日内交易，死鱼口诀：日线顶分型下，就做空；日线底分型上，就做多。" ——高维牛 Q020

2建仓两阶段——先保命，后赚钱

开仓后你的心态应该分成两个截然不同的阶段：

图2：建仓两阶段 · 做空案例
阶段状态核心任务心态
第一阶段还没盈利 / 微亏微赚保本！力求全身而退随时准备跑
第二阶段有了浮动盈利赚得多！移动止损，不急着平仓让利润奔跑
"盈利之前主要任务是保本，有了盈利之后主要任务是赚的多，跟随主趋势，移动止损，不必急着获利了结。" ——高维牛 Q020

3什么时候不做——比"做什么"更重要

高手和新手最大的区别不是怎么赚钱，而是知道什么时候不出手。

图3：三种不交易的走势形态

不交易清单：

  1. 多空势均力敌——反弹幅度≈下跌幅度，时间也差不多 → 不押注
  2. 方向不明朗——走势纠缠在一起，分不清涨跌 → 看看就行
  3. 不是单边流畅走势——走势像夹心饼干来回晃 → 不开仓
  4. 走势胜率不高 → 不下注
  5. 心情不好 → 关电脑出门玩
要捡死鱼，不参与肉搏。不稳赢的事情，没啥干的。
"需要的是单边流畅走势，不是夹心饼干。" ——高维牛 Q020

4「猜」vs「已经」——一字之差，天壤之别

这是新手最容易犯的错。看到前期高点就想"肯定过不去"，提前做空——这叫碰瓷。

图4：「猜突破不了」vs「已经突破不了」的区别
看到价格接近前期高点 → 猜它突破不了 → 提前做空

结果：价格可能直接突破新高，你被打脸止损
价格冲到前期高点附近 → 等它已经冲不过去 → 等它已经开始往回走 → 再做空

结果：确认了空头占优，胜率大增
"真要做空，是他'已经'突破不了，'已经'往回走。正在往上攻，去做空是碰瓷。" ——高维牛 Q020

5趋势 ≠ 走势——别混用这两个词

我之前把这两个概念混着用了，但原文（Q021）有严格区分：

图5：走势 vs 趋势——有没有经过「考验」是关键
走势趋势
定义泛指所有价格运动，几根K线也算经过「考验」（至少一个中继）后依然延续原方向
稳定性低——可能只是假动作高——经历了"肯定→否定→再肯定"
可交易性不一定能做可以放心顺势做
中继数量可能没有至少1个以上
一段价格运动不叫趋势。只有经过反方向的「考验」后继续原方向，才叫趋势。趋势是经过验证的走势。

6方向一致性——频繁切换 = 快速亏损

这条来自Q014和Q032。很多新手看到一个小反弹就切做多，跌一下又切做空——来回被打耳光。

图6：频繁切换多空 vs 坚持方向一致性
下跌中看到反弹 → 切做多
反弹失败又跌 → 切做空
又反弹 → 又切做多

结果：3次交易3次止损
日线下跌确认 → 只做空
反弹出现 → 不管，等反弹到压力位再开空
反弹突破止损 → 退出等待，不反手做多

结果：只在确定性高的位置出手
"在琐屑无聊的波动中反反复复在多空之间频繁切换，妄想通吃所有交易机会，这是快速亏损的最佳策略。" ——高维牛 Q014

7走势分解的唯一性——一种走势只有一种分法

来自Q032。大走势里套着小走势，容易看花眼。解决方法：

图7：走势分解唯一性 · 橡胶5分钟示例

三个关键原则：

  1. 统一周期：选定5分钟，就只看5分钟，不来回切换
  2. 分段唯一：一段走势从方向确认到方向改变，能分解为N段且只能分解为N段
  3. 当下优先：前面是什么走势不是最重要的，你正在做的这一段是什么方向才最重要
"能分解为4个，且只能分解为这4个——这就是唯一性。" ——高维牛 Q032

8少做 = 多赚——降低频率提高胜率

来自Q023。不需要提升任何技术，只需要减少冲动交易，胜率自动提高：

图8：去掉冲动交易后胜率变化
交易次数成功次数胜率
原来（含冲动交易）100次60次60%
去掉冲动交易后80次55次69%
只做高确定性机会30次22次73%
去掉的20次冲动交易里，只有5次成功（胜率25%）。砍掉这些垃圾交易，整体胜率立刻提升。
"啥也没干，甚至干的事情还变少了，胜率却提高了。这就像经营企业，涨价10%难，成本减少10%容易。" ——高维牛 Q023

9隐含前提——散户不能照搬大师

来自Q002和Q012。索罗斯说要结合基本面，傅海棠说基本面第一——他们都对，但隐含前提不同：

图9：不同资金量级的隐含前提对比
索罗斯/大基金散户（你）
资金量千亿美元几万到几十万
周期一年到几年日内到几天
止损幅度50%-100%几个点到几十个点
基本面作用核心驱动力几乎没用（5分钟走势不需要）
建仓方式慢慢建仓几个月一次性开仓
经典期货书里的策略，隐含前提是大资金+长周期。散户几万块钱做日内，要走「散户特色」的制胜之路。
"不能把国外期货书上的理念套在自己身上来用，因为隐含前提不同。散户要走'散户特色'的制胜之路。" ——高维牛 Q012

10持仓量——被忽视的重要指标

来自Q012。期货不看MACD，但持仓量（OPI）很有用。建议用它替换MACD显示在图表底部。

图10：持仓量与走势的关系 · 军事比喻

持仓量的军事解读：

持仓量状态军事比喻交易含义
持仓量小小股部队零星战斗行情小，随时可能被终结
持仓量逐步增加双方不断增兵大行情正在酝酿
盘整中持仓量极大双方陈兵百万，准备恶战突破后将是大行情
持仓量达到极大值倾巢而出物极必反，走势可能转折
持仓量减少部队撤退行情趋于弱势/盘整
"大战都发生在双方投入重兵的时候，全军出动，全力以赴，不管谁输，都是严重的后果。" ——高维牛 Q012
